# 화면 영역 이름 (강의도구 웹)

대화·문서·코드 주석에서 같은 말을 쓰기 위한 이름표. 코드의 id/클래스는 괄호 안.

## 입장 화면
| 이름 | 설명 |
|---|---|
| 입장 카드 (`#login`) | 로그인 폼 전체 |
| 역할 탭 (`#modeTabs`) | 수강생 / 강의자 전환 |

## 강의 화면
| 이름 | 설명 |
|---|---|
| 상단바 (`header`) | 제목, 강의실, 접속자 이름, 테마 버튼 |
| 판서판 (`#board`) | 팔레트 + 무대를 합친 왼쪽 큰 영역 |
| 팔레트 (`#palette`) | 왼쪽 세로 도구 모음(강의자 전용) |
| 무대 (`#stage`) | 영상이 나오는 곳 |
| 판서층 (`#overlay`) | 무대 위에 얹힌 투명 캔버스(그림·글씨가 그려짐) |
| 배경층 (`#boardBgLayer`) | 판서 배경(흰색·칠판 등) |
| 공유 화면 (`#shareV`) | 승인된 수강생의 화면 |
| 사이드 패널 (`aside`) | 오른쪽 전체 |
| 탭 줄 (`nav`) | 채팅 / 질문 / 퀴즈·설문 / 스크린샷 / 참여자 |
| 탭 화면 (`#panes section`) | 탭 하나의 내용 |
| 하단 크레딧 (`footer`) | Produced by yundo |
| 알림 (`#toast`), 확대 보기 (`#lightbox`) | 잠깐 뜨는 메시지, 이미지 크게 보기 |

## 팔레트 안쪽 (위에서 아래)
| 그룹 이름 | 내용 |
|---|---|
| 도구 | 펜·형광펜·지우개·글씨·도형·아이콘 |
| 색 | 색 견본, 색 고르기 |
| 굵기 | 펜 굵기 |
| 크기 | 글씨·아이콘 크기 |
| 배경 | 영상/흰색/칠판/검정/모눈 |
| 캡처 | 저장, 복사 |
| 편집 | 전체 지우기 |

- 그룹 사이의 가로 줄은 **구분선**, 그룹 위의 작은 글자는 **그룹 제목**, 그룹 안의 버튼 한 칸은 **도구 버튼**이라 부른다.
- 아이콘 도구를 누르면 나오는 목록은 **아이콘 선택창**(`#iconPick`).

## 그림판 앱(Tauri)
| 이름 | 설명 |
|---|---|
| 도구줄 | 위쪽: 열기·저장·복사·실행 취소 등 |
| 도구 상자 | 왼쪽: 연필·브러시·이동·선택 등 |
| 옵션 패널 | 색·굵기·칠판 색·글꼴 |
| 캔버스 영역 | 가운데 그림 영역(`#paper`), 위에 눈금자 |
| 상태줄 | 아래: 좌표, 확대 슬라이더 |
