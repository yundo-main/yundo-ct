## 🔴 우선순위 높음 (버그·원인이 명확한 것)

- [x] **라벨이 버튼처럼 보이는 문제**: 패널에 `setObjectName("panel")`을 적용해 패널 스타일이 라벨과 입력 위젯에 전파되지 않도록 수정했다.
- [x] **콤보박스 화살표가 안 보임**: 패널 전용 스타일로 분리하고 드롭다운 영역 폭을 고정했다.
- [x] **"선택 영역 삭제"(▣) 버튼이 눌린 상태로 남음**: 실행 버튼으로 분리해 체크 기능을 제거했다.
- [x] **도구상자 안에 도구상자를 숨기는 버튼이 있음**: 상태 표시줄의 고정 토글과 보기 메뉴/단축키로 이동했다.
- [x] **전경색 툴팁이 실제 동작과 다름**: 색상 대화상자를 연다는 설명으로 수정했다.

## 🟠 레이아웃·시각

- [x] **도구 버튼 배치가 비효율적**: 4열 그리드로 바꿔 세로 공간을 줄였다.
- [ ] **아이콘 의미를 알기 어려움**: ◒(브러시), ▧(선택), ⊠(영역 삭제), ▣(선택 영역 삭제)는 무엇인지 추측하기 힘들다. SVG 아이콘으로 바꾸거나 아이콘 아래에 작은 글자를 붙인다. "영역 삭제"와 "선택 영역 삭제"는 기능이 겹쳐 보이니 하나로 합칠지도 검토한다.
- [x] **선택된 도구가 잘 구분되지 않음**: checked 상태의 배경과 테두리를 강화하고 제목에 현재 도구명을 표시한다.
- [x] **보기 아이콘이 깨지거나 흐림**: 기호 대신 `격자`, `눈금` 텍스트 버튼으로 변경했다.
- [x] **섹션 제목 너비가 제각각**: 패널 전체 폭을 사용하는 공통 제목 영역으로 정리했다.
- [ ] **사이드바 300px 고정 + 하단 여백**: 캔버스 공간을 차지하는 데 비해 아래쪽이 비어 있다. 너비를 200~220px 정도로 줄인다. 패널마다 `setFixedHeight`가 있어서 HiDPI 환경이나 글꼴 크기가 바뀌면 내용이 잘릴 위험도 있다.

## 🟡 색상 패널

- [x] 최근에 사용한 색상 칸을 추가한다.

## 4차 점검 (2026-10-19, 스크린샷 4 기준)

### 🔴 버그

- [x] **회색이 `+`에 가려져 안 보임**: 팔레트 10색 중 회색이 (1, 4) 칸에 놓이는데, `custom_button`도 같은 (1, 4) 칸에 추가된다(`qt_application.py` 857, 864행). 회색 위에 `+`가 겹쳐 있다. 회색을 뺄지, `+`를 다른 곳(최근 색상 줄 끝이나 스와치 옆)으로 옮길지 정한다.
- [x] **도형 도구에 굵기가 적용되지 않음**: 도구 옵션의 "굵기"를 바꿔도 직선·사각형·타원은 `QPen(self.color, 2)`로 고정되어 있다(271행). `self.stroke_width`를 쓰도록 바꾼다.
- [x] **연필과 브러시가 똑같음**: 둘 다 `stroke_width` 하나를 같이 쓴다. 그래서 브러시만의 차이(기본 8px)가 사라졌고, 한쪽에서 바꾸면 다른 쪽도 바뀐다. 도구별로 굵기를 따로 저장한다(예: `{"연필": 2, "브러시": 8, ...}`).
- [x] **콤보박스 화살표가 여전히 빔**: 전역 스타일에서 `QComboBox::drop-down`을 꾸미면 기본 화살표가 사라진다(514행). `QComboBox::down-arrow`에 이미지나 삼각형을 지정하거나, `::drop-down` 스타일을 지운다.
- [x] **팔레트를 한 번 누르면 `_set_color`가 두 번 실행됨**: `PaletteButton.mousePressEvent`에서 한 번, `clicked` 시그널에서 또 한 번 호출된다. `clicked.connect` 쪽을 지운다.

### 🟠 색상 패널

- [x] **전경/배경 스와치가 겹치지 않고 대각선으로 떨어짐**: 150×52 영역 안에 50×34 칸 두 개를 왼쪽 위·오른쪽 아래에 두어서 서로 떨어져 있다. 영역을 약 70×48로 줄여야 그림판처럼 겹쳐 보인다.
