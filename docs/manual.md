# 강의도구 사용 설명서

영상 강의 위에 실시간으로 판서하고, 수강생이 같은 화면을 보며 퀴즈·설문·질문·채팅·화면 공유로 참여하는 도구입니다.
화면 영역 이름은 [ui-names.md](ui-names.md), 서버·API 규약은 [server-api.md](server-api.md)를 보세요.

## 1. 서버 켜고 끄기 (관리자)

서버를 돌리는 PC에서, 프로젝트 폴더(`yundo-ct/`)에서 실행합니다.

```bash
scripts/start.sh   # 강의도구 서버 + MediaMTX(영상)를 백그라운드로 실행
scripts/stop.sh    # 둘 다 종료
```

- 처음 실행하면 서버를 빌드하느라 시간이 걸립니다.
- 실행이 끝나면 접속 주소가 출력됩니다. 로그는 `~/.cache/yundo-ct-run/`(`server.log`, `mediamtx.log`)에 쌓입니다.
- MediaMTX가 없으면 `brew install mediamtx`로 설치합니다.
- 서버와 MediaMTX는 **둘 다** 떠 있어야 영상이 나옵니다. 서버만 켜면 채팅·판서는 되지만 영상은 안 나옵니다.
- 터미널에서 직접 켠 경우(`cargo run ...`, `mediamtx server/mediamtx.yml`)는 `stop.sh`로 끌 수 없고, 해당 터미널에서 `Ctrl+C`로 끕니다.

### 운영 전에 바꿀 값

기본 비밀번호는 누구나 아는 값입니다. 실제 수업에서는 바꿔서 실행하세요.

```bash
LECTURE_SECRET=아무긴문자열 TEACHER_PASSWORD=새비밀번호 ADMIN_PASSWORD=새비밀번호 scripts/start.sh
```

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `8765` | 접속 포트. 바꾸면 `server/mediamtx.yml`의 `authHTTPAddress` 포트도 같이 바꿉니다 |
| `HOST` | `0.0.0.0` (`start.sh`) | 다른 PC 접속을 받으려면 `0.0.0.0` |
| `TEACHER_PASSWORD` / `ADMIN_PASSWORD` | `teacher` / `admin` | 강의자·관리자 비밀번호 |
| `LECTURE_SECRET` | `dev-secret-change-me` | 로그인 토큰 서명 키. 반드시 변경 |
| `TEACHER_ACCOUNTS` | (없음) | 강의자를 더 추가: `"아이디:비밀번호,아이디2:비밀번호2"` (쉼표·콜론은 비밀번호에 쓸 수 없음) |

## 2. 접속하기

| 누가 | 주소 |
|---|---|
| 서버 PC (강의자) | `http://localhost:8765` |
| 다른 PC (수강생) | `http://<서버 PC의 IP>:8765` |

서버 PC의 IP는 `ipconfig getifaddr en0`으로 확인합니다. `start.sh`가 끝에 출력해 주는 주소를 그대로 알려 줘도 됩니다.

### 로그인

로그인 화면에는 **수강생 / 강의자** 탭이 있습니다.

| | 이름 | 비밀번호 |
|---|---|---|
| **수강생** 탭 | 아무 이름 (비워 둘 수 없음) | 비워 둠 |
| **강의자** 탭 | 등록된 아이디 (`teacher`, `admin` 등) | 해당 비밀번호 |

- 수강생 탭에서는 강의자 아이디(`teacher`, `admin`)를 쓸 수 없습니다.
- **같은 강의실(방) 이름**을 입력해야 같은 강의를 봅니다. 강의자가 정한 방 이름을 수강생에게 알려 주세요.
- 수강생마다 다른 이름을 쓰게 하세요. 접속자 명단과 귓속말이 이름으로 구분됩니다.

## 3. 강의자 사용법

### 3-1. 영상 송출

화면 상단의 송출 버튼으로 시작합니다.

| 버튼 | 설명 |
|---|---|
| 카메라 | 내 카메라와 마이크를 송출 |
| 화면 공유 | 모니터 전체를 송출 |
| 창 공유 | 특정 창만 송출 |
| 캠 오버레이 (체크) | 화면·창 공유 위에 내 카메라를 작게 겹쳐 송출. 기본으로 켜져 있어서 카메라 권한을 요청합니다. 카메라가 필요 없으면 끄고 시작하세요 |

- 송출이 시작되면 "● 송출 중"이 표시되고, 소리 크기 막대가 움직입니다.
- 송출을 멈추려면 송출 중지 버튼을 누르거나 브라우저의 "공유 중지"를 누릅니다.
- **카메라·화면 공유는 `localhost` 또는 HTTPS 주소에서만 됩니다.** 강의자는 서버 PC에서 `http://localhost:8765`로 접속하세요. 서버 IP(`http://172.16...`)로 접속하면 브라우저가 막습니다.
- macOS에서는 시스템 설정 → 개인정보 보호 및 보안 → **화면 및 시스템 오디오 녹화**에서 브라우저를 허용해야 화면 공유가 됩니다.

### 3-2. 판서

영상 위에 그림과 글씨를 올립니다. 수강생 화면에 실시간으로 같이 보입니다.

- 왼쪽 **팔레트**에서 도구를 고릅니다: 펜, 형광펜, 지우개, 글씨, 도형, 아이콘.
- 색, 펜 굵기, 글씨·아이콘 크기를 바꿀 수 있습니다.
- **배경**을 영상 / 흰색 / 칠판 / 검정 / 모눈 중에서 고를 수 있습니다. 영상 없이 칠판처럼 쓸 때 편합니다.
- **캡처**로 판서 화면을 저장하거나 복사합니다.
- **전체 지우기**는 판서를 모두 지웁니다.
- 늦게 들어온 수강생도 지금까지의 판서를 그대로 받습니다.

### 3-3. 퀴즈·설문

오른쪽 패널의 **퀴즈·설문** 탭에서 발행합니다.

- **OX 퀴즈**: 문제를 발행하면 수강생이 답을 고릅니다. 집계는 강의자에게만 보이고, 종료하면 마감됩니다.
- **설문**: 발행하면 수강생에게도 집계가 실시간으로 보입니다. **익명** 옵션이 있고, 익명이 아니면 누가 골랐는지 강의자에게만 보입니다.

### 3-4. 질문 관리

수강생이 올린 질문이 **질문** 탭에 쌓입니다. 답한 질문은 체크해서 완료 처리합니다. 수강생의 **손들기**는 강의자에게만 알림이 갑니다.

### 3-5. 코드 공유

코드 블록(스니펫)을 올리면 수강생 화면에 표시되고, 복사 버튼으로 가져갈 수 있습니다.

### 3-6. 수강생 화면 공유 승인

1. 수강생이 **화면 공유 요청**을 누릅니다.
2. 강의자 화면에 요청 목록이 뜨면 **허용** 또는 **거절**합니다. 한 번에 한 명만 공유할 수 있습니다.
3. 허용된 수강생이 화면을 고르면 모두에게 그 화면이 보입니다.
4. 끝낼 때는 발표자가 직접 끝내거나, 강의자가 **중지**합니다.

한계: 강의자가 허용을 취소해도 이미 연결된 송출을 서버가 강제로 끊지는 못합니다. 수강생 화면이 중지 신호를 받아 스스로 끊습니다.

### 3-7. 채팅과 파일

- 전체 채팅과 **귓속말**(특정 사람에게만)이 있습니다. 한 번에 500자까지 보낼 수 있습니다.
- 파일 첨부는 20MB까지이고 실행 파일 형식은 거부됩니다. 이미지는 채팅에서 바로 보이고 클릭하면 크게 봅니다.
- 채팅 기록은 서버를 다시 켜도 복원됩니다 (최근 200개).

## 4. 수강생 사용법

1. 강의자가 알려 준 주소로 접속합니다. 예: `http://172.16.24.25:8765`
2. **수강생** 탭에서 이름과 강의실 이름을 입력하고 입장합니다. 비밀번호는 비워 둡니다.
3. 강의자가 송출을 시작하면 화면에 영상이 자동으로 나타납니다. 송출 전에는 대기 화면이 보이고, 3초마다 자동으로 다시 연결을 시도합니다.

화면이 나왔는데 소리가 없으면 화면을 한 번 클릭하세요. 브라우저가 자동 재생 소리를 막은 것입니다.

### 할 수 있는 것

| 기능 | 방법 |
|---|---|
| 퀴즈·설문 응답 | 강의자가 발행하면 **퀴즈·설문** 탭에 나타납니다. 선택지를 누르면 제출됩니다 |
| 질문하기 | **질문** 탭에서 질문을 올립니다 |
| 손들기 | 손들기 버튼 (강의자에게만 알림) |
| 채팅·귓속말 | **채팅** 탭. 받는 사람을 고르면 귓속말입니다 |
| 파일 보내기 | 채팅의 첨부 버튼 (20MB까지) |
| 화면 공유 | 공유 요청 버튼 → 강의자가 허용하면 화면을 선택해 공유 |
| 스크린샷 | **스크린샷** 탭에서 영상과 판서를 함께 캡처 |
| 접속자 보기 | **참여자** 탭 |

- 화면 공유는 수강생 PC에서도 `localhost` 또는 HTTPS가 필요합니다. `http://IP:8765`로 접속한 수강생은 영상은 볼 수 있지만 화면 공유 송출은 브라우저가 막습니다 ([6. 문제 해결](#6-문제-해결-도움말) 참고).
- 퀴즈·설문에서 익명이 아닌 설문은 강의자에게 내 선택이 보입니다.

## 5. 녹화와 다시보기

두 가지를 따로 저장하고 다시보기에서 합칩니다.

1. **영상**: 송출이 시작되면 MediaMTX가 자동으로 저장합니다 (1시간 단위, 30일 후 자동 삭제).
2. **판서·퀴즈·질문 등**: 강의자가 **● 녹화 시작**을 눌렀을 때부터 기록됩니다. 강의자가 모두 나가면 자동으로 닫힙니다.

**다시보기**는 `http://localhost:8765/replay`에서 합니다. 토큰, 녹화 파일, 영상 주소를 넣고 불러오면 영상 재생에 맞춰 판서가 다시 그려지고, 코드·질문 타임라인을 누르면 그 시점으로 이동합니다.

- 판서 기록의 0초는 **녹화 시작을 누른 시점**입니다. 영상은 송출 시작부터 기록되므로, **송출 직후에 녹화 시작**을 누르세요. 어긋나면 다시보기의 오프셋(ms)으로 맞춥니다.
- 방 이름은 영문·숫자·`-`·`_`(64자 이하)일 때만 녹화·채팅 저장이 됩니다. 한글 방 이름은 접속은 되지만 저장되지 않습니다.
- 녹화 파일에는 수강생 이름과 질문이 들어 있으므로 보관 기간과 접근 권한을 정해서 다루세요. 저장 위치는 `server/recordings/`, `server/chatlogs/`, `server/uploads/`이고 Git에는 올라가지 않습니다.

## 6. 문제 해결 (도움말)

| 증상 | 확인할 것 |
|---|---|
| 접속 자체가 안 됨 | 서버가 떠 있는지(`scripts/start.sh`), 주소와 포트(`:8765`)가 맞는지, 같은 네트워크인지 확인. 서버가 `HOST=127.0.0.1`로 떠 있으면 다른 PC에서 접속할 수 없습니다 (`start.sh`는 기본 `0.0.0.0`) |
| 로그인이 안 됨 | 수강생 탭에서 `teacher`/`admin`을 쓰면 거절됩니다. 강의자는 **강의자 탭**에서 로그인하세요. 비밀번호도 확인 |
| "카메라 권한이 필요합니다" | **캠 오버레이**가 켜져 있어서 카메라를 요청한 것입니다. 카메라가 필요 없으면 체크를 끄고 다시 시작. 필요하면 주소창 자물쇠에서 카메라·마이크를 허용 |
| 화면 공유·카메라 버튼이 아무 반응이 없음 | `http://서버IP:8765`로 접속한 경우입니다. 브라우저가 HTTPS나 `localhost`가 아닌 주소에서는 막습니다. 강의자는 `http://localhost:8765`로 접속하거나, HTTPS를 적용하거나, Chrome에서 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`에 해당 주소를 등록 (PC마다 설정) |
| 강의자 화면 공유가 검은 화면이거나 목록이 비어 있음 (macOS) | 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹화 → 브라우저 허용 후 브라우저 재시작 |
| 송출은 되는데 수강생에게 영상이 안 보임 | 1) MediaMTX가 떠 있는지 2) 강의자가 먼저 송출했는지 3) 강의실 이름이 같은지 4) 다른 PC라면 서버 PC의 방화벽에서 TCP 8889, UDP·TCP 8189가 열려 있는지 5) 학생 PC에서 `http://서버IP:8889`가 열리는지. 가상머신·VPN이 있는 PC는 `server/mediamtx.yml`의 `webrtcAdditionalHosts`에 서버 IP를 넣습니다 |
| 영상은 나오는데 소리가 없음 | 화면을 한 번 클릭 (브라우저 자동재생 정책) |
| `송출 실패 (403)` | 강의자 탭이 아닌 수강생 탭으로 로그인했거나 토큰이 만료됐습니다. 다시 로그인 |
| 서버 IP가 바뀌어서 안 됨 | IP는 공유기(DHCP)가 바꿀 수 있습니다. 새 IP로 접속하고 `server/mediamtx.yml`의 `webrtcAdditionalHosts`도 고친 뒤 `stop.sh` → `start.sh` |
| `start.sh`가 "이미 실행 중"이라고 함 | `scripts/stop.sh`로 끄고 다시 실행 |
| 시작 실패 | `~/.cache/yundo-ct-run/server.log`, `mediamtx.log`를 확인. 포트 8765/8889가 이미 쓰이고 있으면 이전에 직접 켠 프로세스를 먼저 종료 |
| 판서·퀴즈 등 강의자 기능이 수강생 화면에서 막힘 | 정상입니다. 강의자 전용 기능을 수강생이 보내면 서버가 거부합니다 |

### 알려진 한계

- 계정은 데모용입니다. 수강생은 이름만으로 입장하고 비밀번호나 본인 확인이 없습니다. 같은 이름으로 여러 명이 들어올 수 있습니다.
- 서버를 다시 켜면 진행 중이던 퀴즈·설문·판서 상태는 사라집니다 (채팅은 복원됩니다).
- HTTPS가 적용되어 있지 않아 외부 인터넷에 그대로 공개하면 안 됩니다. 교내·사내 네트워크에서 쓰세요.
- 영상 녹화와 판서 기록의 시각은 자동으로 맞춰지지 않습니다 (다시보기에서 수동 오프셋).
