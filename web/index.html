    도움말

    자세한 내용은 사용 설명서(docs/manual.md)에 있습니다.

    수강생: 이렇게 사용하세요
    • 강사가 송출을 시작하면 영상이 자동으로 나타납니다. 소리가 없으면 화면을 한 번 클릭하세요.
    • 채팅: 받는 사람을 고르면 귓속말입니다. 클립 버튼이나 드래그로 파일(20MB까지)도 보낼 수 있습니다.
    • 질문 탭에서 질문을 올리고, 손들기 버튼으로 강사에게만 알릴 수 있습니다.
    • 퀴즈·설문: 강사가 발행하면 이 탭에서 선택합니다. 실명 설문은 강사에게 내 선택이 보입니다.
    • 내 화면 공유 요청: 요청하면 강사가 허용할 때 내 화면을 모두에게 보여 줄 수 있습니다.
    강의자: 이렇게 사용하세요
    • 영상 아래 카메라 / 화면 공유 / 창 공유로 송출합니다. 송출·녹화 중에는 영상 오른쪽 위에 빨간 배지가 표시됩니다.
    • 영상 위를 드래그하면 판서합니다. 왼쪽 팔레트에서 도구·색·굵기·배경(영상/흰색/칠판/검정/모눈)을 고릅니다.
    • 녹화는 판서·퀴즈·질문을 기록합니다. 송출 직후에 눌러야 영상과 시각이 잘 맞습니다. 다시보기에서 확인합니다.
    • 퀴즈·설문 탭에서 발행하고, 끝나면 CSV로 저장합니다. 수강생 화면 공유 요청은 참여자 탭에서 허용합니다.
    • 카메라가 필요 없으면 캠 오버레이 체크를 끄고 화면 공유를 시작하세요.
    영상이 안 나와요
    • 강사가 먼저 송출을 시작했는지, 강의실(방) 이름이 같은지 확인하세요.
    • 다른 PC에서 접속했다면 서버 PC에서 영상 서버(MediaMTX)가 실행 중이어야 하고, 방화벽에서 TCP 8889 / UDP·TCP 8189가 열려 있어야 합니다.
    • 소리만 안 나오면 화면을 클릭하세요(브라우저 자동재생 정책).
    카메라·화면 공유가 안 돼요
    • 브라우저는 https 또는 localhost 주소에서만 카메라·화면 공유를 허용합니다. 서버 PC에서 http://localhost:포트로 접속하세요.
    • 주소창 자물쇠에서 카메라·마이크를 허용하세요. macOS는 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹화에서 브라우저를 허용해야 합니다.
    • 송출 실패 (403)이면 강의자 탭이 아니라 수강생 탭으로 로그인한 것입니다. 다시 로그인하세요.
    화면 구성
    • 오른쪽 탭: 채팅 / 질문 / 퀴즈·설문 / 스크린샷 / 참여자. 새 소식이 있으면 탭에 빨간 점이 뜹니다.
    • 상단 오른쪽 ◐ 버튼은 화면 테마(자동/밝게/어둡게)를 바꿉니다.
